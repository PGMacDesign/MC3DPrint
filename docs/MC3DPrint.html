🔨 Crafting Method by Tier

T1–T4: Single craftable block. Craft it in a crafting table, place it in the world. Done. T3 and T4 are more powerful single-block machines — not multiblocks.

T5–T8: Require multiblock assembly — specific blocks must be placed in-world in the correct configuration. No crafting table recipe. The machine forms when the structure is complete. The higher the effort, the more impressive the machine.

📦 Multiblock Portability — Collapse to Item

Multiblock machines are fully portable without disassembly. The effort is in building it, not moving it.

🔧 Formation
  1. Place component blocks in correct layout
  2. Right-click the controller block
  3. Multiblock forms into one logical unit
  4. Component blocks become rendered structure
📦 Relocation
  1. Break the controller block
  2. Entire multiblock collapses instantly
  3. Drops as a single item (e.g., "Tier 5 Fabricator")
  4. Place it anywhere → machine reforms automatically

No inventory tetris. No lost components. No rebuilding from scratch. Build it once, relocate freely.

⚡ Power — Redstone Flux

RF Compatibility

Standard RF power grid — works with Thermal Expansion, Mekanism, EnderIO, Draconic Evolution, and any RF-producing mod.

Power-Loss Behavior

If RF cuts out mid-print, the job pauses and resumes exactly where it left off when power is restored. No matter lost. No partial structure mess. GUI displays PAUSED — Insufficient Power.

🧵 Filament System

All fabrication is powered by Filament Units (FU) — a unified measurement of stored material potential. There is no separate "Raw Matter" pool. FU is the single currency for both storing and spending material.

The Flow

1. Feed materials into the Filament Winder → converts to FU, winds onto a blank spool
2. Load the spool onto the printer sides (Shift+Right Click)
3. Printer draws FU from the spool as it prints
4. RF consumed at both steps — winding and printing

Filament Unit Values

Conversion is symmetric — what a material yields in FU is exactly what it costs to print it. Materials within the same group share identical FU values. Diamond = Emerald. Cobblestone = Dirt = Gravel = Sand.

Tier Down-Conversion (One Direction Only)

Higher-tier materials can be processed down by one tier at a 16:1 FU ratio. 1× T5 material → 16× T4 material's worth of FU.

Cannot tier up. Hard restriction. Prevents cobblestone farming from trivializing the economy.

Down-conversion is one step at a time: T6→T5→T4, not T6→T3 directly.

🧵 Filament Spool System

Rather than dumping raw materials directly into the printer, they're first processed through a Filament Winder into a physical Filament Spool item. The spool loads into the printer and is consumed during printing — visibly spinning on the machine exterior as it unwinds.

🔧 Filament Winder Machine

Separate machine that accepts raw materials (top input) and winds them into a Filament Spool at the output. Tiered T1–T8 — higher tiers wind faster and accept higher-tier materials. Simple top-in / front-out I/O, same as the printer.

🧵 Spool Attachment & Slots

  • Shift + Right Click the side of the printer in-world to attach or detach a spool
  • Slots are on the left and right sides of the machine (Snapmaker U1-style placement)
  • Auto-switches to the next loaded spool when one depletes — no print interruption
  • Hover in GUI to see remaining FU as fill bar + %
  • Depletion with no backup spool pauses the printer, never loses progress

🔧 Enhancements & Expansion Slots

Slot count mirrors tier: T3 = 3 slots, T7 = 7 slots, T8 = 8 slots. Modifiers stack multiplicatively.

⚡ Speed Upgrade

Increases print head movement speed. Faster prints per tier of upgrade.

🧪 Efficiency Upgrade

Reduces FU cost per print. Get more filament out of each spool.

🪨 Matter Density Upgrade

Better conversion rate for low-value inputs. Cobblestone goes further.

🔋 RF Efficiency Upgrade

Reduces RF consumption per block placed.

📦 Buffer Upgrade

Increases internal Matter and RF storage capacity.

Upgrades are themselves tiered — a T1 Speed Upgrade vs. a T5 Speed Upgrade provide meaningfully different performance. All values tunable in config.

🧫 Resins (Print Modifiers)

A Resin is a consumed-per-print modifier dropped into the printer/fabricator's Resin slot. It refines the next blueprint print, then is used up. Resins work only on official/found blueprints — never player-scanned ones — the anti-exploit gate that stops a player scanning a cheap build and mass-printing value.

🌱 Verdant Growth

In-place plants (crops, nether wart, sweet berries, cocoa) print fully grown. T1–T2.

✨ XP Yield

The print banks XP, furnace-style, released when you pull the disc from the output slot. T1–T3.

💰 Treasure Infusion

Printed chests/barrels/shulkers may spawn holding loot (Common/Rare/Epic tables). T2–T3.

⚡ Overdrive

The print costs less filament — T2 = break-even, T3 = ~20% below (net FU gain). T2–T3.

📦 Quartermaster

Printed furnaces/brewing-stands/chests arrive stocked — fuel, plus a move-in kit with enchanted iron tools. T3.

⛏️ Ore Salting

Printed natural stone has a chance to come out as a mineable ore vein. T3.

Crafting: a shared Resin Base (Extrudium Crystal + any slimeball) + a tier ingredient (a diamond/emerald for T2) + an effect ingredient. T1–T2 are craftable; T3 is loot-only, found at ~10% in end-game chests via a global loot modifier.

Anti-exploit: every value-minting effect is multiply-gated — official-blueprints-only + consumed-per-print + (T3 unfarmable / T2 gem-cost) + per-print caps + the winder-blacklist and down-only/exact-tier winding — so none can become a duplication engine. All chances and amounts live in the resin config section.

🔌 I/O Design

Anti-AE2-Inscriber. No side-specific requirements. No "silicone in the right, redstone in the top" nonsense.

Rules

  • Top face — accepts any input: matter materials, blueprint discs, anything going in
  • Bottom / Front face — output: finished items, ejected discs
  • Works with vanilla hoppers at T1 — zero gatekeeping on early automation
  • Compatible with EnderIO conduits, Thermal ducts, Mekanism pipes, AE2 import/export buses, RS cables
  • Output buffer pauses the printer if full — never voids items
  • Blueprint disc returns to output slot after print completes
  • Side faces — reserved exclusively for Filament Spool attachment (Shift+Right Click). Not general I/O.

⚗️ AE2 Integration — Filament Unit Converter

Only exists / is craftable / is visible if Applied Energistics 2 is installed. Fully hidden without AE2 present.

A dedicated block that bridges the ME network directly into the filament system — the end-game automation unlock. As long as the configured materials exist anywhere in the ME network, the printer's filament supply is effectively infinite.

🎨 Appearance
  • Attaches to the AE2 system like an addon/peripheral
  • Metal-framed block with a physical filament spool protruding from it
  • Spool spins slowly while actively converting
  • Looks like the ME network has its own filament supply
⚙️ GUI & Behavior
  • Player configures which items/materials to auto-convert
  • Listens to ME network for available stock of configured items
  • Automatically pulls and converts on demand
  • Responds in real-time — conversion resumes when stock is restocked
  • Works with full ME system: import/export buses, channels, autocrafting
  • Only processes items explicitly configured — no accidental consumption

🌐 Multiplayer & Server Features

🚧 Print Zone Conflict Detection

Mod-internal only — no external claim mod dependency. If an active print job occupies an area and another printer tries to print in the same space, it throws an error and refuses to start. Simple bounding box overlap detection.

📦 Built-in Chunk Loading

When a print job starts, all chunks in the print volume are automatically force-loaded. Released when the job completes, pauses, or cancels. No external chunk loader required — works reliably for T6/T7 mega-prints.

📡 Remote Terminal Block

Pairs to a specific printer. Full control from anywhere: load blueprints, check matter/RF, start/stop/queue prints. Multiple terminals per printer. Essential when the multiblock is deep inside a build.

🗄️ Server Blueprint Repository

Blueprints stored as world/mc3dprint/blueprints/*.blueprint files on disk. Server owners manage the folder directly. Modpack makers can pre-populate it. Accessible in-game via a Repository block or library tab.

Locked Design Decisions

✅ No machine durability — permanent investments, not maintenance

✅ No tier-up matter conversion — prevents cobblestone farm exploits

✅ Soft dependencies only — standalone mod, integrations are bonuses

✅ Multiplicative modifier stacking — prevents runaway enhancement values

✅ Power-loss pauses, never resets — no punishment for infrastructure mistakes

🌟 Stretch Goals

✨ Print Completion Effect

Visual flourish when a job finishes: beam of light, fireworks, satisfying sound. The "done" moment should feel genuinely rewarding.

💠 Hologram Idle Animation

When idle, the printer displays a slowly rotating hologram of the last blueprint printed. Purely cosmetic, looks amazing.

🎨 Printer Skin System

Dye or skin the printer frame cosmetically. Drives screenshots, community showcases, and engagement without affecting gameplay.

🔁 Deconstruct Mode

Printer runs in reverse — breaks down a structure and converts it back to Filament Units. Clean demolition with FU recovery.

📋 Batch Blueprint Sequencing

Chain multiple blueprints into a single automated sequence: print A, then B, then C — fully unattended.
